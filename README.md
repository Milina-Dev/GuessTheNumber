# GuessTheNumber
Программа для игры "Угадай число"

## Возможности

- Программа загадывает случайное число от 1 до 100.
- Подсказывает, больше или меньше загаданное число.
- Проверяет правильность ввода.
- Подсчитывает количество попыток.
- Позволяет выйти из игры с подтверждением.

## Управление

Введите число от 1 до 100, чтобы попробовать угадать загаданное число.

Введите "0", чтобы выйти из игры.
